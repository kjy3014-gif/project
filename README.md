# 정렬 퀘스트 - 숫자 줄서기 대작전

알고리즘과 난이도를 고른 뒤 게임을 시작하세요.
버블은 교환 여부, 선택은 최솟값, 삽입은 들어갈 자리, 퀵은 Pivot의 확정 위치를 맞혀요.
시간 제한은 스피드 모드에서만 적용됩니다.
정답 콤보로 점수를 얻고, 라운드를 통과하면 숫자 개수가 늘어납니다.
기존의 네 가지 정렬 시각화 앱은 `visualizer.html`에서 확인할 수 있습니다.
상단의 ‘게임 받기’ 버튼은 오프라인 실행용 `sort-quest-game.html` 파일을 내려받습니다.
게임을 바꾼 뒤 오프라인 파일을 새로 만들려면 `node build-game.js`를 실행하세요.
